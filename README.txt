Демонтаж проф — standalone v2

Файлы:
- index.html — весь сайт целиком: стили, JavaScript, реальная аватарка и фото встроены внутрь.
- .nojekyll — для GitHub Pages.

Проверка:
1) распакуйте архив;
2) откройте index.html двойным кликом;
3) для GitHub Pages загрузите index.html и .nojekyll прямо в корень репозитория.

Работающие кнопки:
- звонок;
- WhatsApp;
- Яндекс Карты;
- навигация;
- мобильное меню;
- форма-бриф в WhatsApp;
- увеличение фото.
